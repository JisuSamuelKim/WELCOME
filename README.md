# WELCOME to the Universe

**WELCOME** (WEak-Lensing COnvergence Map Emulator) is a fully theory-driven framework for generating stochastic full-sky weak-lensing convergence-map realisations from cosmological parameters and a source population.

WELCOME uses theoretical non-linear angular power spectra, theoretical covariance and stochastic power-spectrum realisations, together with theoretical multi-scale wavelet L1-norm constraints. No simulation calibration is used in the generation framework.

## Installation

Install WELCOME from PyPI:

```bash
pip install welcome-to-the-universe
```

Alternatively, install the latest development version directly from GitHub:

```bash
pip install git+https://github.com/JisuSamuelKim/WELCOME.git
```

For development from a local clone:

```bash
pip install -e .
```

## Minimal use

```python
from welcome import WelcomeConfig, run_welcome

config = WelcomeConfig(
    h=0.70,
    omega_b=0.046,
    omega_cdm=0.233,
    sigma8=0.82,
    n_s=0.97,
    single_plane=True,
    source_redshift=1.0334,
    nside=512,
    n_realisations=10,
)

result = run_welcome(config)
```

For a source redshift distribution, set `single_plane=False` and provide `nz_file` as a NumPy `.npy` array with shape `(N, 2)` or `(2, N)`, containing `z` and `n(z)`.

### Display a generated map

Each generated realisation is saved to disk, and its path is available in `result["emulation_results"]`.

To load and display the first generated convergence map:

```python
import numpy as np
import healpy as hp
import matplotlib.pyplot as plt

map_path = result["emulation_results"][0]["map_path"]
kappa_map = np.load(map_path)

hp.mollview(
    kappa_map,
    title="WELCOME convergence map",
    unit=r"$\kappa$",
)

plt.show()
```

## Example notebook

`examples/run_WELCOME.ipynb` demonstrates the complete workflow and displays:

- one generated full-sky convergence-map realisation,
- the configured source population,
- matched theoretical and emulated power-spectrum realisations,
- theoretical and emulated wavelet L1-norm curves at 15-30, 18-36, 20-40, and 25-50 arcmin,
- L1-weighted variance, skewness, and excess kurtosis.

The theoretical wavelet L1 prediction at a fixed cosmology and source population is deterministic. The moment comparison therefore shows one theoretical value per wavelet scale and an empirical distribution across the generated map realisations.

## Outputs

Theoretical power-spectrum products are stored as compressed `.npz` files.

Generated convergence maps are stored in `.npy` format.

Wavelet L1 products and diagnostic products generated by the example notebook are cached as `.npz` files inside the selected output directory.

Existing compatible outputs can be loaded and reused without rerunning the full generation pipeline.

## Reproducibility

Each emulated map realisation is associated with its corresponding stochastic theoretical power-spectrum realisation.

Map realisations are generated independently and can be parallelised.

WELCOME is theory-driven throughout the generation stage. Simulations, when used, serve only as independent validation benchmarks and are not used for calibration.
